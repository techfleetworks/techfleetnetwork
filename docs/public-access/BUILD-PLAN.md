## Principles (from the Week 4 Language-of-Change method + ticket)

- **Non-functional before functional:** schema → security → gateways → CI, *then* UI, *then* discoverability/launch.
- **Expand / contract:** additive first; the anon lockdown (PR6) comes only after consumers move to the gateway (PR3). **PR3 must land before PR6.**
- **Feature-flagged:** the public surface stays behind a flag until PR15 flips it; rollback = flag off.
- **Every PR ships its own ADR + Gherkin (@security where relevant) + tests.** No PR is "done" without them (Definition of Done, CLAUDE.md).
- **One decision = one ADR** in `docs/adr/` with a date-ID (`YYYYMMDD-slug`).
- **Visibility is a business rule:** it lives in the Strategy policy + gateway, never in a screen (Week 4 step 7).
